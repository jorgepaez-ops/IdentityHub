Flujo SSO: Contabilidad e Identity Hub

OAuth 2.0 Authorization Code con PKCE (ADR 0009). Contabilidad es un cliente público: no tiene secreto, PKCE lo sustituye, y nunca ve la contraseña. El token es un JWT firmado con EdDSA que el cliente verifica con el JWKS del Hub.
