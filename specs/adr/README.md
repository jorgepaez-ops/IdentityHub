# Decisiones de arquitectura (ADR)

Formato: contexto → decisión → consecuencias, incluidas las malas. Una decisión
cuyas contrapartidas no se escriben no se ha entendido del todo.

Estados: `propuesta` · `aceptada` · `sustituida por NNNN` · `revertida`
